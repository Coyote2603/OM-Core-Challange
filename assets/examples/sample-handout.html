Miniature example

A fictional study group must choose the format for its final review meeting.

Frame
Choose a format that helps members practise the topics they find hardest within one meeting.
Signal
Anonymous requests show whether members need application practice or a conceptual recap.
Rule
Use live practice if most requests concern application; use a guided recap otherwise.
Review
End with one transfer question and ask members whether the chosen format prepared them to answer it.

Reflection

Where in your own course do learners see a conclusion without seeing the reasoning that produced it? Name one frame, signal, or rule you could make more explicit.
