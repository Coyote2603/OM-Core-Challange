# Licensing guide

This repository uses different licenses for software and educational expression. The distinction lets others build on the infrastructure while preserving clear attribution for the original demo teaching content.

## Source code

The source code is licensed under the [MIT License](LICENSE). This includes the implementation in:

- the root HTML files;
- `css/**`;
- the program logic and configuration structure in `js/**`;
- `scripts/**`; and
- `.github/**`.

You may use, modify, redistribute, and sublicense that code subject to the MIT notice.

## Original demo educational content

The original synthetic educational examples, explanatory prose, diagrams, exercises, answers, session copy, and project documentation are licensed under [Creative Commons Attribution 4.0 International](LICENSES/CC-BY-4.0.txt), abbreviated CC BY 4.0. The [canonical license page](https://creativecommons.org/licenses/by/4.0/) provides a human-readable summary and translations.

This category includes:

- the synthetic teaching content in `js/content.js`;
- the instructional wording of the OM Core Challenge, including question context, hints, and worked solutions;
- `README.md`, `ACKNOWLEDGMENTS.md`, and `docs/**`; and
- any future file explicitly labeled as demo educational content.

When reusing or adapting this content, give appropriate credit, link to CC BY 4.0, and indicate whether you made changes. A suitable attribution is:

> Adapted from the Interactive Teaching Platform by Stefanos Poulidis, licensed under CC BY 4.0. Changes were made.

The functional code surrounding educational wording remains available under MIT. If a file contains both, the code structure is MIT-licensed and the expressive teaching content is CC BY 4.0.

## Not licensed by this repository

The licenses above do not cover:

- private, password-protected, or institutionally restricted course materials;
- exercises, assessments, recordings, cases, datasets, or solutions created by third parties unless they are separately and explicitly licensed;
- student submissions, student data, or classroom recordings;
- institutional names, seals, logos, trademarks, or brand assets; or
- third-party libraries and assets listed in [Third-party notices](THIRD_PARTY_NOTICES.md).

In particular, this repository does not contain or license original INSEAD tutorial exercises developed or refined by Jiatao Ding, Bengisu, Clara Carrera, or other INSEAD PhD colleagues. Their acknowledgment describes intellectual and teaching context, not a transfer of copyright or permission.

## Contributions

By submitting a contribution, you represent that you have the right to contribute it. Unless you state otherwise in the pull request:

- contributed code is provided under MIT; and
- contributed demo educational content and documentation are provided under CC BY 4.0.

Do not contribute material copied from a textbook, publisher resource, restricted course site, student submission, employer, or institution unless its license clearly permits public redistribution and you document that permission.

## Questions

This guide clarifies the repository's intended licensing structure but is not legal advice. If ownership or permission is uncertain, leave the material out until the relevant rights holder or institution confirms public-release terms.
